# Interview-Prep

A personal collection of notes and cheatsheets for interview preparation, organized by topic.

## Structure

```
Interview-Prep/
├── data-structures/    # Arrays, Linked Lists, Trees, Graphs, Heaps, Hash Maps
├── algorithms/         # Sorting, Searching, Dynamic Programming, Recursion
├── system-design/      # Design patterns, Scalability, Databases, Caching
└── behavioral/         # STAR method, common questions, tips
```

## Topics

| Folder | Contents |
|---|---|
| [`data-structures/`](./data-structures/) | Core data structure cheatsheets with complexity tables |
| [`algorithms/`](./algorithms/) | Algorithm patterns, templates, and complexity references |
| [`system-design/`](./system-design/) | System design frameworks and component notes |
| [`behavioral/`](./behavioral/) | Behavioral interview frameworks and question banks |

## Quick Reference — Big-O Complexity

| Operation | Array | Linked List | Hash Map | BST (avg) |
|---|---|---|---|---|
| Access | O(1) | O(n) | O(1) | O(log n) |
| Search | O(n) | O(n) | O(1) | O(log n) |
| Insert | O(n) | O(1) | O(1) | O(log n) |
| Delete | O(n) | O(1) | O(1) | O(log n) |

## How to Use

1. Browse to the topic folder you want to review.
2. Each folder contains one Markdown file per topic with notes, examples, and complexity tables.
3. Use GitHub's search (`t` key on any page) to quickly find a keyword across all notes.
